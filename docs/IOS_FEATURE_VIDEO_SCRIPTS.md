## Capture requirements

- Use moving iOS footage with clearly visible actions and resulting feedback.
- Episode 2/3's example must actually show 18 and bucket 9; rewrite narration
  if the selected footage uses different values.
- Do not use the automated expert run as an example of misses; capture deliberate
  incorrect landings through the production controls for episode 5.
- Verify labels and results on-screen before each final narration generation.
- Use fictional display details and a dedicated test account for account footage.
  Local injected authentication callbacks simulate success, so they cannot
  substantiate a real sign-in or saved-account claim.
- Capture leaderboards only with a working, populated test session. The local
  capture entry point's leaderboard placeholder is excluded from all media.
- No purchases, account deletion, or public posting are required for this series.

## Per-video delivery

Landscape 1920×1080 YouTube master, vertical 1080×1920 version, English captions,
thumbnail, title, description, social link copy, and narration provenance.
Put “Narration is AI-generated” in the visible video treatment and description.
Use the actual published YouTube URL in social copy only after upload.
